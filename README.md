# Source Tester

Focused five-source Avengers: Endgame compatibility tester, hosted at https://cydpixl.github.io/source-tester/.

CineSrc, ScreenScape, Cinextream, VidCore, and VidRift only. The four strongest sources open sandbox tests first. VidRift opens an explicit Normal test because interaction triggers its sandbox rejection; its sandbox test remains available for comparison.

Each player opens in a separate tab. Mark Works, Blocked, Does not play, or Sandbox issue and optionally add a note. Playback telemetry never establishes that the picture and controls work. Sandbox, normal, and direct results remain separate and persist in this browser. Export results downloads a JSON report to share manually. No account is required. No data is sent to another person automatically.

The tester measures compatibility and records filter blocks; it does not change network filtering. An iframe load does not count as successful playback. Earlier short observations do not guarantee continued playback or correct film identity.

The previous full research dataset is preserved in sources-research-archive.json. Existing result storage keys remain unchanged. GitHub Pages publishes the repository root from main.
